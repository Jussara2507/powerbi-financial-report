# powerbi-financial-report
📊 Desafio de Power BI: Relatório Financeiro com Foco em UX

Este repositório armazena a entrega do projeto final de Business Intelligence (BI), com foco na otimização da experiência do usuário (UX), modelagem de dados e design intuitivo em painéis executivos.

🚀 Sobre o Projeto

O objetivo principal deste desafio foi transformar um relatório analítico tradicional em um painel dinâmico e focado nas necessidades de negócio, aplicando conceitos avançados de design e usabilidade:

Proporção Áurea e Posicionamento Visual: Hierarquia de informações destacando os KPIs principais no terço superior da tela.

Contraste e Estilização: Utilização de cores corporativas equilibradas e fundos modernos para facilitar a leitura.

Interatividade Avançada: Implementação de botões de navegação com estados dinâmicos de Focalizar (Hover) e Selecionar (Click).

Segmentação Eficiente: Filtros limpos e dinâmicos para segmentação rápida dos dados financeiros.

🛠️ Ferramentas Utilizadas

Power BI Desktop (Modelagem de Dados, DAX, Power Query)

Power BI Service (Publicação e compartilhamento na nuvem)

Git e GitHub (Versionamento e portfólio de projetos)

📑 Estrutura do Relatório (3 Páginas)

Página 1 - Visão Geral e KPIs Executivos: Indicadores principais de faturamento, lucro e unidades vendidas com filtros globais.

Página 2 - Análise de Desempenho: Detalhamento por produto e comportamento comercial.

Página 3 - Matriz Analítica: Tabela cruzada detalhada de vendas e margens de lucro.
